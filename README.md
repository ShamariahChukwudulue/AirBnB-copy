# Airbnb Clone

A functional responsive frontend website inspired by the Airbnb platform. The project was developed using **HTML, CSS, and JavaScript** to practice responsive interface development and frontend interactivity.

> This project is an educational implementation inspired by the Airbnb user interface and is not affiliated with or endorsed by Airbnb.

## Features

* Responsive navigation
* Interactive navigation menu
* Property listing cards
* Horizontal property-card scrolling
* Search interface
* Destination/category sections
* Navigation interactions
* Show-more/show-less functionality
* Login interface
* Form-related interactions
* Responsive layouts for different screen sizes
* Mobile-friendly interface

## Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling and responsive layouts
* **JavaScript** — Interactivity and dynamic behavior

## How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Open the main HTML file in a web browser.

No backend server or database is required.

## Interactive Features

JavaScript is used to make several parts of the interface interactive.

For example, the navigation menu can be opened and closed through user interaction. The project also includes horizontal scrolling for property cards and other frontend interactions.

## Responsive Design

The website is designed to adapt to different screen sizes using CSS responsive techniques and media queries.

The interface can be tested using browser Developer Tools to simulate different desktop, tablet, and mobile screen sizes.
